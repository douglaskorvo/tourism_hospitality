# Destination hospitality from visitor reviews — analysis code

Code and derived outputs for *Destination Hospitality as an Emergent Property
of Commercial Host–Guest Encounters: Evidence from 50,180 Visitor Reviews
across Twenty-Nine Emerging-Economy Cities*.

Everything here runs from a single input file and reproduces every number in
the manuscript, the three figures and all sixteen sheets of the supplementary
workbook.

---

## What is not in this package

**The review corpus itself (`reviews_raw.csv`) is not included.** It is
user-generated content retrieved through the Google Places API and is
redistributable only under that platform's terms; the collection protocol is
described in Section 3.1 of the manuscript. Place the file at the path set in
`RAW` at the top of `scripts/code_reviews.py` before running anything.

Three large intermediates are also omitted because they are regenerated by the
pipeline: `out/w2v.model` (the trained skip-gram model),
`out/reviews_coded.parquet` (the coded review table) and
`out/marker_matrix.npy` (the review-by-marker occurrence matrix).

`out/candidate_terms.csv` is withheld for a different reason. It is the raw
seed-expansion list produced by step 2, and it carries the personal names that
the gazetteer of step 3 exists to remove. Publishing it would put reviewers'
and employees' first names into the supplementary record, which the study's
ethics statement undertakes not to do. Step 2 regenerates it locally in about
ninety seconds. For the same reason the borderline-term list exported for
supplementary sheet S16 withholds every token that occurs anywhere in the
author-name field, not merely those above the gazetteer threshold.

## Environment

Python 3.11 with:

```
pandas 3.0    numpy 2.4      scipy 1.17     statsmodels 0.15
gensim 4.4    scikit-learn 1.8               openpyxl
pyarrow       matplotlib 3.10
```

All randomness is seeded. The skip-gram model uses seed 42; every bootstrap,
permutation and split-half draw is seeded from the *name of the statistic
being computed* (`rng_for()` in `scripts/analysis.py`), so no result depends on
the order in which the scripts happen to consume the generator. Rerunning the
pipeline from scratch reproduces the reported figures exactly.

## Run order

The scripts are not independent; run them in this order.

| # | Script | What it does | Runtime |
|---|--------|--------------|---------|
| 1 | `code_reviews.py` | Normalises the text with explicit clause boundaries, applies the theory-derived service- and destination-quality dictionaries from `lexicon.py`, resolves referents, handles negation. Writes `out/reviews_coded.parquet`. | ~4 min |
| 2 | `induce_vocab.py` | Trains the skip-gram model on the 50,180 reviews and expands from the hospitality seeds. Writes `out/w2v.model`, `out/candidate_terms.csv`. | ~1.5 min |
| 3 | `build_markers.py` | The contrastive filter that separates hospitality from generic praise, the personal-name gazetteer, the topical exclusions, and the review-by-marker matrix. Writes `out/markers.csv`, `out/marker_matrix.npy`, `out/discriminant_terms.csv`. | ~2 min |
| 4 | `typology_final.py` | Clusters the marker groups and selects k by bootstrap stability. Writes `out/typology.csv`. | ~25 s |
| 5 | `named_host.py` | Flags reviews that name the person who hosted them, using the same gazetteer as step 3. Writes `out/named_host.csv`. | ~2 min |
| 6 | `analysis.py` | Prevalence, city scores with the supplier bootstrap, reliability, discrimination, convergent and discriminant validity, and the RQ2 models. Writes `out/city_scores.csv`, `out/reliability.csv`, `out/discrimination.csv`, `out/analysis_log.txt`. | ~25 s |
| 7 | `robustness.py` | Translation, expressiveness, platform-coverage and segment robustness, plus leave-one-country-out. Writes `out/city_index_variants.csv`, `out/city_profiles.csv`, `out/loo_rq2.csv`, `out/robustness_log.txt`. | ~40 s |
| 8 | `induction_audit.py` | The induction funnel, the threshold sensitivity sweep, the borderline terms and the k-selection table (supplementary sheet S16). | ~4 min |
| 9 | `figures.py` | Figures 1–3 as 300 dpi PNGs in `fig/`. | ~20 s |
| 10 | `export_supp.py` | Exports every reported quantity as tidy CSVs under `out/supp/`, carrying the raw counts rather than the derived values. | ~2 min |
| 11 | `build_workbook.py` | Assembles the supplementary workbook, deriving each reported quantity with a live spreadsheet formula over those counts. | ~10 s |

Supporting modules, not run directly:

- `lexicon.py` — the service-quality and destination-quality dictionaries, with every marker declared unambiguous or ambiguous, plus the provider and destination referent anchors.
- `fastfe.py` — the within (fixed-effects) estimator with cluster-robust standard errors. Supplier effects are absorbed by demeaning because estimating 11,477 dummy variables at this sample size is infeasible.
- `topical_stopwords.txt` — the 166 topical terms excluded during vocabulary induction. **This is the one investigator-dependent step in the procedure** (Section 3.3); the list is deposited here precisely so that each call is inspectable and reversible.
- `kwic.py` — keyword-in-context sampler used for the precision audit reported in Table 3.

## Superseded scripts

These are kept for the record. They are earlier attempts that the final
analysis does **not** use, and they are retained because the reasons they
failed are part of the method's justification.

- `typology.py` — clustered inflected surface forms rather than morphological groups. The clusters organised themselves by Portuguese gender and number agreement (*atencioso* with *caloroso*, *atenciosa* with *calorosa*) rather than by meaning. This is why the final procedure folds morphology before clustering.
- `typology_nmf.py` — non-negative matrix factorisation of the review-by-marker matrix. Topic coherence rose monotonically with k without ever stabilising, and the resulting types overlapped heavily on the same high-frequency markers. Superseded by embedding-space clustering with bootstrap stability selection.
- `factor_structure.py` — PCA with varimax rotation and Horn's parallel analysis. Parallel analysis over-retains badly with sparse binary indicators at n = 50,180, returning seventeen fragmentary components. Kept because the negative result is worth knowing.

## A note on what the code does and does not do

No supervised model is fitted anywhere in this pipeline and no labelled data
are used. The skip-gram model supplies a geometry of co-occurrence; the
hospitality instrument is a dictionary derived from that geometry by explicit,
inspectable filters; and the constructs are then validated against quantities
they were not built from. Where a decision rested on the investigator's
judgement rather than on a rule — the topical exclusions, the two retention
thresholds, the removal of undirected enthusiasm from destination quality —
the manuscript says so and this package contains what is needed to overturn it.

## Scope

This package covers the analysis only: how the reported quantities were
produced from the review corpus. It contains no manuscript file and no
tooling for assembling one. The article was written and revised by the
authors.
